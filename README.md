# Blinkit Grocery Sales Analysis Dashboard

## Project Overview
This project analyzes grocery sales data using Microsoft Power BI. The dashboard presents important business metrics, sales trends, and product performance to support better business decisions.

## Objectives
- Analyze grocery sales performance.
- Identify top-performing product categories and outlets.
- Understand customer preferences and sales trends.
- Present key performance indicators through interactive visualizations.

## Tools Used
- Microsoft Power BI
- Microsoft Excel
- Power Query
- DAX

## Key Features
- Sales and business KPI analysis
- Product and category performance
- Outlet-wise sales analysis
- Interactive filters and visualizations
- Data cleaning and transformation

## Files Included
- `blinkit.pbix` — Power BI dashboard file.
- `BlinkIT Grocery Data.xlsx` — Source dataset.

## How to Use
1. Download the PBIX file from this repository.
2. Open it in Power BI Desktop.
3. If required, update the Excel data source path.
4. Explore the dashboard using the available filters and visualizations.
